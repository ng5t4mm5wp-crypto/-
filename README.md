# ساجِل الراوي

لعبة **مساجلة شعرية صوتية** من مخزون يضم ١٠٠٠ بيت عربي موزّعًا على ١٤
بحرًا. يقول الراوي بيتًا، وعلى اللاعب أن يردّ ببيت يبدأ بآخر حرف منه.

## طريقة اللعب

1. يعرض الراوي بيتًا من الديوان.
2. تستخرج اللعبة آخر حرف معاملةً التاء المربوطة تاءً والألف المقصورة ياءً.
3. ينشد اللاعب بيتًا بصوته أو يكتبه.
4. تطابق اللعبة النص المتعرّف عليه مع المخزون مع تجاهل التشكيل وفروق الهمزات.
5. إذا صح البيت ولم يُستخدم من قبل، يرد الراوي ببيت يبدأ بآخر حرف منه.

## المؤقّت

- مدة قابلة للضبط من ١٠ إلى ١٢٠ ثانية.
- إعدادات سريعة: ٢٠ أو ٣٠ أو ٦٠ ثانية، أو اللعب بلا مؤقّت.
- زيادة أو إنقاص خمس ثوانٍ أثناء الدور.
- إيقاف واستئناف المؤقّت في أثناء المساجلة.

## التعرّف الصوتي

تسجل اللعبة الصوت عبر `getUserMedia`، ثم تحوّله إلى نص داخل المتصفح بنموذج
Whisper Base متعدد اللغات بواسطة Transformers.js. لا تعتمد النسخة الحالية على
`SpeechRecognition` أو خدمة الإملاء الشبكية في Chrome.

يتحكم اللاعب بالميكروفون يدويًا بالكامل: يضغط لفتحه، وتظهر الكلمات على دفعات
أثناء الإنشاد، ثم يضغط «أغلق واعتمد البيت» بنفسه. لا يؤدي الصمت إلى الإغلاق أو
إرسال الإجابة. ويُصحَّح التفريغ تلقائيًا إلى أقرب بيت في الديوان عندما تكون
المطابقة واثقة. يعمل التحليل في Web Worker كي تبقى واجهة اللعبة مستجيبة.

يتطلب أول استعمال تنزيل النموذج المضغوط، ثم يحتفظ به المتصفح في ذاكرته
المحلية للاستخدامات التالية. توجد الكتابة اليدوية احتياطًا للأجهزة التي لا
تدعم Web Audio أو عند تعذّر التنزيل. للحصول على أفضل تجربة استخدم نسخة حديثة
من Chrome أو Edge عبر اتصال HTTPS.

## التشغيل والاختبار

لا يحتاج المشروع إلى عملية بناء:

```bash
npm run serve
```

ثم افتح <http://localhost:4173>. ولتشغيل اختبارات المخزون ومنطق المساجلة:

```bash
npm test
```

## البيانات

جميع الأبيات في `data/verses.json`. راجع
[`DATA_SOURCES.md`](DATA_SOURCES.md) للمصدر ومنهج اختيار العينة والتنبيه
الحقوقي.
