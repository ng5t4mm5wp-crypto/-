# ساجِل الراوي

لعبة **مساجلة شعرية صوتية** من مخزون يضم ١٠٠٠ بيت عربي موزّعًا على ١٤
بحرًا. يقول الراوي بيتًا، وعلى اللاعب أن يردّ ببيت يبدأ بآخر حرف منه.

## طريقة اللعب

1. يعرض الراوي بيتًا من الديوان.
2. تستخرج اللعبة آخر حرف معاملةً التاء المربوطة تاءً والألف المقصورة ياءً.
3. ينشد اللاعب بيتًا بصوته أو يكتبه.
4. تطابق اللعبة النص المتعرّف عليه مع المخزون مع تجاهل التشكيل وفروق الهمزات.
5. إذا صح البيت ولم يُستخدم من قبل، يرد الراوي ببيت يبدأ بآخر حرف منه.

## المؤقّت

- مدة قابلة للضبط من ١٠ إلى ١٢٠ ثانية.
- إعدادات سريعة: ٢٠ أو ٣٠ أو ٦٠ ثانية، أو اللعب بلا مؤقّت.
- زيادة أو إنقاص خمس ثوانٍ أثناء الدور.
- إيقاف واستئناف المؤقّت في أثناء المساجلة.

## التعرّف الصوتي

تستخدم اللعبة واجهة Web Speech API عند توفرها، مع اللغة `ar-SA` والنتائج
المؤقتة وخمسة بدائل للمطابقة. يتحكم اللاعب بالميكروفون يدويًا بالكامل:
يضغط لفتحه، ويرى الكلمات المتعرّف عليها أمامه، ثم يضغط «أغلق واعتمد البيت»
عندما ينتهي. لا يؤدي الصمت إلى إغلاق الميكروفون أو إرسال الإجابة. وإذا أنهى
المتصفح محرك التعرف داخليًا، تعيد اللعبة تشغيله مع إبقاء النص الظاهر.
يبدأ الميكروفون فقط بعد ضغط اللاعب وموافقته.

تستخدم اللعبة `SpeechRecognition` مباشرةً ولا تفتح مسار `getUserMedia`
موازيًا؛ لأن الجمع بين المسارين قد يسبب خطأ `audio-capture` في بعض إصدارات
Chromium. وعند توقف التعرف لسبب نهائي تعرض الواجهة رمز الخطأ بدل إخفائه.
قد يعالج المتصفح الصوت محليًا أو عبر خدمة خارجية وفقًا لتنفيذه.

ليست واجهة التعرف الصوتي متاحة في كل المتصفحات؛ لذلك توجد كتابة يدوية
احتياطية. للحصول على أفضل تجربة استخدم نسخة حديثة من Chrome أو Edge عبر
اتصال HTTPS.

## التشغيل والاختبار

لا يحتاج المشروع إلى عملية بناء:

```bash
npm run serve
```

ثم افتح <http://localhost:4173>. ولتشغيل اختبارات المخزون ومنطق المساجلة:

```bash
npm test
```

## البيانات

جميع الأبيات في `data/verses.json`. راجع
[`DATA_SOURCES.md`](DATA_SOURCES.md) للمصدر ومنهج اختيار العينة والتنبيه
الحقوقي.
