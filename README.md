# ساجِل الراوي

لعبة ويب عربية تختبر الذاكرة الشعرية ومعرفة البحور من مخزون يضم **١٠٠٠
بيت حقيقي** موزّعًا على ١٤ بحرًا.

## أنماط اللعب

- **أكمل البيت:** اختيار عجز البيت الصحيح من أربعة اقتراحات.
- **اعرف البحر:** تحديد البحر الشعري لبيت كامل.
- **مجلس الراوي:** جولة مختلطة بين النمطين.

كل لعبة من عشر جولات، مع مؤقت ونظام نقاط وسلاسل إجابات صحيحة. تُحفظ أفضل
نتيجة محليًا في المتصفح، وتعمل اللعبة بعد الزيارة الأولى دون اتصال.

## التشغيل

لا يحتاج المشروع إلى بناء أو حزم خارجية:

```bash
npm run serve
```

ثم افتح <http://localhost:4173>. وللتحقق من المخزون والشيفرة:

```bash
npm test
```

يمكن نشر الملفات مباشرةً عبر GitHub Pages من جذر الفرع `main`.

## البيانات

جميع الأبيات مخزّنة في `data/verses.json`. راجع
[`DATA_SOURCES.md`](DATA_SOURCES.md) للمصدر، ومنهج اختيار العينة، والتنبيه
الحقوقي.
